# Google Sheets 스키마

## 운영 설정

### 시험

시험 공개 상태, 대상 반, 과목, 문항 수, 총점, 선택지 수와 마감 시간을 관리합니다. 학생에게 노출할 시험은 `상태`를 `공개`로 바꿉니다.

### 학생

학생 ID, 이름, 반, 사용 여부와 PIN 해시를 관리합니다. 원본 연락처와 확인번호 평문은 이 시트에 저장하지 않습니다.

### 문항

시험별 문항 번호, 정답, 배점, 유형을 보관합니다. Apps Script가 제출 시 이 값을 읽어 다시 채점합니다.

## 최종 제출 원장

### 제출

학생 한 명의 시험 한 회 제출을 한 행으로 보관합니다. `student_id + exam_id`는 논리적으로 유일합니다. 답안 최종 제출 직후 `answer_locked=TRUE`, 복기 최종 제출 후 `reflection_complete=TRUE`가 됩니다.

### 제출문항

제출의 문항별 답, 서버 정답, 배점, 정오, 획득 점수를 보관합니다. 복기 최종 제출 때 `reflection_category`와 `mistake_reason`만 갱신합니다.

### 전체복기

잘한 점, 아쉬운 점, 다음 행동과 자유 메모를 제출당 한 행으로 보관합니다. 복기를 다시 최종 제출하면 같은 행을 갱신합니다.

### 도움요청

문항별 도움 유형과 메모, 처리 상태를 보관합니다. 학생이 복기 수정에서 요청을 빼면 행을 삭제하지 않고 `active=FALSE`로 바꿉니다. 선생님은 `status`를 `NEW`, `CHECKED`, `DONE`으로 관리할 수 있습니다.

## 쓰기 시점

| 학생 행동 | Google Sheets 기록 |
|---|---|
| 로그인 | 없음 |
| 답안 입력·수정 | 없음 |
| 답안 최종 제출 | `제출` 1행 + `제출문항` 문항 수만큼 |
| 복기 선택·수정 중 | 없음 |
| 복기 최종 제출 | 복기·도움 요청 upsert |

`upsert`는 기존 제출 ID의 행이 있으면 갱신하고 없으면 새 행을 추가한다는 뜻입니다.
