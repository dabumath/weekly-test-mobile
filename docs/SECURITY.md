# 보안 경계

- 운영 시트는 비공개로 유지합니다.
- 학생 명단 파일, 스프레드시트 ID, PIN, 비밀키는 저장소에 커밋하지 않습니다.
- PIN은 원본 명단에서 마지막 4자리만 읽고, 이름과 함께 HMAC-SHA256으로 해시한 값만 운영 시트에 기록합니다.
- 로그인 실패는 같은 정규화 이름 기준 10분에 5회로 제한합니다.
- 세션은 HMAC 서명하며 기본 유휴 30분, 최대 120분입니다. 서버 캐시가 사라지면 다시 로그인해야 합니다.
- Apps Script 브리지는 등록된 정확한 parent origin과 nonce, iframe 창, 요청 ID를 확인합니다.
- 모든 쓰기는 학생 세션과 시험 대상 반을 재검증합니다.
- 답안은 Apps Script가 비공개 `문항` 시트의 정답과 배점으로 다시 채점합니다.
- 답안 최종 제출은 Script Lock과 요청 ID로 중복 쓰기를 막습니다.
- 오류 응답에는 학생 존재 여부, PIN 해시, 정답, 내부 예외 내용을 넣지 않습니다.

이름과 확인번호 4자리는 학원 내부 학생을 구분하기 위한 간단한 절차이며 강한 본인 인증은 아닙니다. 민감도가 높은 성적 공개나 결제·법적 동의에는 별도 인증이 필요합니다.
