# 파일럿 테스트 시나리오

처음에는 고1·고2를 섞어 3~5명만 테스트합니다. 테스트 전 운영 시트를 복사해 백업하고, 대상 시험만 잠시 `공개`로 둡니다.

## 로그인

- 정확한 이름과 확인번호로 로그인됩니다.
- 이름 앞뒤 공백과 연속 공백은 정리됩니다.
- 잘못된 정보는 학생 존재 여부를 드러내지 않는 같은 오류 문구를 보여줍니다.
- 연속 실패 5회 뒤에는 잠시 차단됩니다.
- 다른 반 시험은 보이지 않습니다.

## 답안 최종 제출

- 입력 중에는 `제출`, `제출문항`에 새 행이 생기지 않습니다.
- 미응답을 포함해 최종 제출할 수 있습니다.
- 최종 제출 후 `제출` 1행과 `제출문항` 25행만 생깁니다.
- 정답·배점 기준의 수동 계산과 서버 점수가 일치합니다.
- 제출 버튼을 빠르게 두 번 눌러도 중복 행이 생기지 않습니다.
- 새로고침하거나 다시 로그인해도 답안은 수정할 수 없습니다.

## 복기 최종 제출

- 복기 선택 중에는 시트 값이 바뀌지 않습니다.
- 정답 문항에는 정답용 범주, 오답 문항에는 오답용 범주만 제출됩니다.
- `실수로 틀림`에서 실수 원인 선택은 선택 사항입니다.
- 최종 제출 후 문항별 복기, 전체 복기, 도움 요청이 반영됩니다.
- 마감 전 `복기 수정` 후 다시 제출하면 기존 행을 갱신하며 중복 행을 만들지 않습니다.
- 삭제한 도움 요청은 행이 사라지지 않고 `active=FALSE`가 됩니다.

## iPhone

- Safari의 작은 화면에서도 답안 입력 한 문항이 한 화면에 들어옵니다.
- 하단 홈 인디케이터 영역과 버튼이 겹치지 않습니다.
- 키보드가 열린 뒤에도 로그인·전체 복기 제출 버튼을 누를 수 있습니다.
- 화면 회전과 앱 전환 뒤 세션 복원이 동작합니다.
- 30분 이상 활동이 없으면 임시 데이터 삭제 안내 후 로그인 화면으로 돌아갑니다.

## 마감과 평균

- `상태=준비중`인 시험은 로그인 후 노출되지 않습니다.
- 제출 마감 뒤 답안 최종 제출이 거절됩니다.
- 복기 마감 뒤 복기 수정·제출이 거절됩니다.
- 같은 반 제출 인원이 최소 기준보다 적으면 평균 수치를 숨깁니다.
